## 🎯 Features

### Stream Source Selection
1. **Internal Stream (Local RTMP/HLS)**
   - RTMP: `rtmp://localhost:1935/live`
   - HLS: `http://localhost:8081/live/.m3u8`
   
2. **External Stream (Custom URL)**
   - User inputs any valid stream URL
   - Supports RTMP, HLS, HTTP, RTSP protocols

### Real-time Processing
- Live video capture from stream
- People detection on each frame
- Visual annotations with bounding boxes
- Real-time statistics display
- Configurable frame dimensions

### Recording
- Optional recording of processed stream
- Timestamp-based file naming
- Saves to `./data/output/videos/live_recordings/`
- Statistics file generation

### Interactive Controls
- **Q key**: Stop processing
- **S key**: Toggle statistics display in terminal
- **Ctrl+C**: Emergency stop

### Statistics Tracking
- Frame count
- People detected per frame
- Maximum people detected
- Average people per frame
- Processing FPS
- Total elapsed time

## 📁 Directory Structure

New directories automatically created:
```
data/output/videos/
├── lives/              # Processed livestream outputs
├── live_recordings/    # Recorded streams (if recording enabled)
└── stats/             # Statistics files for streams

nginx-rtmp-stream/
└── stream/            # HLS files generated by nginx (.m3u8, .ts)
    └── live/          # Created when streaming starts
```

**Important**: The `nginx-rtmp-stream/stream/` directory is managed automatically by the nginx-rtmp server and should not be edited manually.

## 🔧 Configuration

### Stream-specific settings in `config.json`:

```json
"stream": {
  "local_rtmp_url": "rtmp://localhost:1935/live",
  "local_hls_url": "http://localhost:8081/live/.m3u8",
  "hls_stream_directory": "./nginx-rtmp-stream/stream",
  "output_directory": "./data/output/videos/lives",
  "recording_directory": "./data/output/videos/live_recordings",
  "stats_directory": "./data/output/videos/stats",
  "dimensions": {
    "width": 1280,
    "height": 720
  }
}
```

**Configuration Details:**
- `local_rtmp_url`: RTMP stream endpoint for local server
- `local_hls_url`: HLS playlist URL for local server  
- `hls_stream_directory`: Where nginx-rtmp generates HLS files (.m3u8, .ts) - managed automatically by nginx
- `recording_directory`: Where processed and recorded streams are saved
- `stats_directory`: Where statistics files are saved
- `dimensions`: Resolution for processing (affects performance and accuracy)

### Inference parameters apply to streams:

```json
"inference_parameters": {
  "conf": 0.1,
  "iou": 0.45,
  "classes": [0],
  "verbose": false
}
```

Adjust these for stream processing:
- **conf**: Higher values (0.3-0.5) reduce false positives in busy streams
- **iou**: Keep at 0.45 for balanced detection
- **classes**: [0] for people-only detection

## 🚀 Usage Flow

1. User selects option 1 (Livestream processing) from main menu
2. System asks: Internal or External stream?
3. **If Internal**: Choose RTMP or HLS protocol
4. **If External**: Enter custom stream URL
5. System asks: Record the processed stream? (y/n)
6. Stream processing starts
7. Live window shows processed video with annotations
8. Statistics printed every 30 frames (if enabled)
9. Press Q to stop processing
10. Statistics summary displayed
11. If recorded, files saved with timestamp

## 🔍 Technical Details

### Class: `StreamProcessor`

**Methods:**
- `__init__(config)`: Initialize processor with configuration
- `select_stream_source()`: Interactive source selection
- `_select_internal_stream()`: Choose RTMP or HLS
- `_select_external_stream()`: Input custom URL
- `process_stream(stream_url, record)`: Main processing loop
- `start_processing()`: Entry point with full workflow

### Dependencies
- cv2 (OpenCV): Video capture and display
- datetime: Timestamp generation for recordings
- PeopleDetector: YOLO-based detection
- VideoWriterManager: Threaded video writing
- StatisticsTracker: Real-time statistics
- draw_detections: Frame annotation

### Error Handling
- Stream connection failures
- Invalid URLs
- Network interruptions
- Keyboard interrupts (Ctrl+C)
- General exceptions with traceback

## 🔐 Security Notes

- Local RTMP server exposes ports 1935 (RTMP) and 8081 (HLS)
- Ensure firewall rules are appropriate for your use case
- External streams: Be cautious with URLs containing credentials
- Recorded streams may contain sensitive information
